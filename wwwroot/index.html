While this tool is connected to PLCSIM, the official PLCSIM control panel can't connect (it shows "no connection to PLCSIM Advanced"). Maintenance mode disconnects this tool from PLCSIM without stopping the service. It powers off the PLCs this tool powered on.
⚠️ No login: anyone who can open this page can power PLCs on and off. Use it only on a trusted, closed network, never on the internet.

⚠️ Change the auto-start cap

The auto-start cap is the most PLCs that auto-start powers on when the machine boots.

If it is higher than the machine can run at once, the machine can freeze while those PLCs start. Auto-start runs on every boot, so it can freeze again after each restart. A built-in loop-breaker turns auto-start off after a few failed boots in a row, but until then the machine is unusable. Only raise it if you are sure the machine can run that many PLCs at once.
